## 🚀 Featured open source

### [agy-headless-bridge](https://github.com/rhishi99/agy-headless-bridge)
[![PyPI](https://img.shields.io/pypi/v/agy-headless-bridge.svg?style=flat-square&color=7c5cff)](https://pypi.org/project/agy-headless-bridge/)
[![MCP Registry](https://img.shields.io/badge/MCP%20Registry-listed-7c5cff?style=flat-square)](https://registry.modelcontextprotocol.io/v0/servers?search=agy-headless-bridge)
![Stars](https://img.shields.io/github/stars/rhishi99/agy-headless-bridge?style=flat-square)

Runs Google's Antigravity CLI (`agy`) headlessly from subprocesses, CI, MCP servers and other agents. It does this by giving `agy` a real pseudo-terminal (Windows ConPTY or POSIX pty) and cleaning the output. It ships as a Python library, a CLI and a **dependency-free MCP server**. It's on **PyPI**, listed in the **official MCP Registry**, and tested with GitHub Actions. [Docs](https://rhishi99.github.io/agy-headless-bridge/)
`Python` · `pty/ConPTY` · `MCP` · `GitHub Actions`

### [hermes-model-auto-switch](https://github.com/rhishi99/hermes-model-auto-switch)
Keeps a working coding model configured for Hermes Agent. A scheduled job runs every 15 minutes. It health-checks NVIDIA NIM models, reads a cross-provider failover router's live model set, and scores candidates using a SQLite learning DB. It then atomically rewrites the fallback model slots, and it detects and replaces models that have been retired upstream. The project has CI, docs and published before/after proof runs. [Docs](https://rhishi99.github.io/hermes-model-auto-switch/)
`Python` · `LLM routing` · `Health checks` · `SQLite` · `CI`

### [OutLoud](https://github.com/rhishi99/OutLoud)
A local text-to-speech plugin for Claude Code and Grok Build. It narrates agent replies on demand, or automatically, with **zero extra LLM tokens**. It uses edge-tts neural voices with native and pyttsx3 fallbacks, and runs on Windows, macOS, Linux and WSL. [Docs](https://rhishi99.github.io/OutLoud/)
`Python` · `Node.js` · `Claude Code plugin` · `TTS`

### [ComboCoder](https://github.com/rhishi99/ComboCoder)
A local-first, four-agent coding assistant: planner, architect, engineer and reviewer. It runs on free-tier LLM APIs and switches provider automatically when one hits a rate limit.
`Python` · `Multi-agent` · `LiteLLM`

### Upstream contributions: [rtk-ai/rtk](https://github.com/rtk-ai/rtk/pulls?q=author%3Arhishi99)

## 🤖 How I use AI

- **AI-assisted engineering:** I use coding agents such as Claude Code for pipeline and infrastructure tooling. **Every change still goes through normal engineering review.** AI speeds up the work; it does not replace review or ownership.
- **MCP tooling:** I build and publish MCP servers so agents can call real tools safely and predictably.
- **Reliability for agents:** model failover and health checks, headless/CI-friendly wrappers, and token-saving utilities. These are the same reliability habits I use in DevOps, applied to AI tooling.
